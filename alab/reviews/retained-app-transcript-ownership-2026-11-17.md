# Native App transcript ownership and preparation

The live-update goal remains active. This change composes actual App history and
focused-widget presentation through the existing whole-scene cell, text, editor,
copy-scope and guard tables. It does not supply complete App/BottomPane/backend
state, advertise full-scene capability, issue a Native grant, certify an application,
or prove an end-to-end update.

App capture registers main/side/overlay/held-bookmark/unprinted-queue roots before
weak edges. It retains the actual transcript viewport, widget transcript and
stream controllers, native output queue, history-tail and usage-tail caches,
deferred rich lines, original replay buffer, reflow deadlines, backtrack state and
chosen tip exposure. Transcript overlay capture covers all fifteen native fields.
Every editor still belongs to the one enclosing editor encode.

Native turn-tip storage uses an ALab-owned Cow type: normal source literals borrow,
while retained chosen text owns its lifetime even when the destination removes
that catalogue entry. Existing selection, rendering and exposure policy remain.
Three original fixtures use the same literal helper for the representation change.

Bottom-pane prerequisites retain exact physical keys/hints, activation guard,
status/timer/preview/footer state and by-value layouts. The immutable keymap graph
preserves actual editor/chord aliases and all raw binding vectors. Only genuine
internal dispatch occurrences rebind through authenticated source action/token
inventory and the destination's actual registered action; physical keys, order and
duplicates stay exact. Context/name ambiguity never synthesizes an action.

Preparation borrows actual editor/selection owners until fallible field resolution
finishes. Typed failures preserve original input and already prepared/admitted native
parts for retry; App fields move only in the final infallible section install.
Retry checks the same context and actual resource bindings, refreshing the private
active-cell cache through its captured theme rather than trusting an earlier admission.
No renderer, clipboard, frame, channel, callback, command or backend permission is
created from selectors or decoded DATA.

The alias control compares the actual complete native chord allocation matrix.
Native leader registration performs copy-on-write and updates Chat while retaining
older pager/list allocations; assuming all fields shared one Arc was incorrect.
The correction changes the test expectation, not the native codec's alias behavior.
