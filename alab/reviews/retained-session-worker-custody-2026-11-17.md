# Original session resources, metadata and worker custody

The live-update goal remains active. This component captures complete native
BackendSessions DATA and binds it to the same complete original local resources.
It does not create a cross-exec Session/client/credential owner, advertise a
complete App/frame, grant Native permission or qualify a shipping application.
Retained candidates remain refused until a genuine owning-resource issuer exists.

All actual backend slots, preference keys, original event FIFO, listening state,
side startup state, parked input snapshots, display/fair-next selection and settings
DATA use one enclosing scene. Native ThreadInputState contains plain drafts and
queues; other actual TextArea owners still belong to the one outer editor encode.
Binding preflights the entire resource set before consuming original native owners,
and failures return the input plus every supplied resource.

Owning-session metadata includes original request namespace/counter, paging,
attachments/focus/revisions, task paths/generation, mode/provider/history support,
cloud/default/model state, prefetch cache, daybreak gate and resource-presence facts.
One alias table preserves original semaphore/generation identities. A real builder
wrapper owns its native ConfigBuilder and a weakly captured incarnation; reconnect
clones get a new incarnation, so address reuse cannot inherit old identity.

Native ModelPreset serde deliberately skips multi_agent_version. Both the catalog
and prefetched successful results use the same explicit codec for this field.
Direct canonical JSON decoding rejects silent defaulting/unknown nested shape;
ordinary protocol serialization rules for omitted None fields remain intact.
No model/list request is repeated to repair observer cancellation or decode failure.

The original prefetch worker/result, title stages, picker and experimental-feature
child retain their real task handles before polling. Canceled join observers return
the same handle to its owner; worker loss stays uncertain. Physical shutdown is
itself retained before await and attempts client shutdown, model joins, changing
original-work joins and Native tenure closure despite an earlier error. The first
ordinary shutdown observer receives the exact native result/error.

A local closed capture is not a promise that no later original App handler can
schedule work. Original native scheduling/cleanup keeps its policy; a final actual
App/event/input cut and currentness recheck remain mandatory before handoff.

Session/SDK children were explicitly unioned; current widget hooks were preserved.
