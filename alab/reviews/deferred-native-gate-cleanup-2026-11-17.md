# Advance deferred gate cleanup without manufacturing native readiness

The earlier widest-check review left genuine native upgrade transitions and
whole-scene restore integration unfinished. A fresh read-only host query returned
`OK native source-exec preparation=1 execution=unavailable input-fence=1`.
The current source requires execution=available, real published source and
destination images, an independently identified host and typed input ownership.
Existing Cargo V8/stdio/CodeMode prerequisites do not supply those contracts.
Decision: preserve the previous failed native cases and defer that execution;
do not forge replies, paths or grants, change ignores, or repeat unchanged tests
whose necessary host capability is explicitly unavailable.

The whole-App/ConfiguredApp/Tui capture/execute/restore assembly also remains
real engineering work. Current image capture has test callers only, and prepare
and installation have no production caller. A leaf call cannot replace the
missing shared scene/Invocation encoder, retained Offer and complete pre-paint
installation. This is not a human hold or a completed integration claim.

Available gate work is narrower. The sealed `9702cade3b` diagnostic inventory
contains 15 unused-import rows. Twelve name declaration-only facades in six
ALab-owned retained-state files. Commit `3118634de0416519e263603442fd6ea6628cef48`
removes those twelve reexports and six associated Unix attributes. It retains
their underlying modules, definitions, methods, resource owners and guards.
The used image Book/Phase exports remain. Independent source review found no
consumer of a removed alias. No fake use, visibility expansion, suppression or
runtime-body edit is introduced.

The three remaining rows are marked facades in upstream-owned files. They are
unchanged here; the hook-count gate is not waived. This bounded deletion reduces
obsolete exposure while keeping incomplete runtime implementations visible.
It does not advertise a complete scene or remove essential image/unlink owners.

Verification compares only the affected codex-tui package before and after,
using the gate's ordinary all-targets Tippy command, source-selected Trust 15698,
genuine V8 inputs, native target admission and the existing protected profile.
The global Trust 27009 shim is not the source-selected compiler. The command
preserves the gate's no-deps/keep-going/JSON/cap-lints-warn behavior; warnings
remain recorded rather than being reclassified as a clean gate.

runs completed successfully, with stable per-run inputs, but the complete Git
maps showed 14 changed paths. The branch had been created from a moving
`origin/main` after concurrent work advanced it. The cleanup commit's actual
parent is `bb7f29af32f578476d3628b012ebced49bd7d4d8`, and that direct-parent
diff contains only the six intended files and 18 deletions. Do not attribute
the mixed comparison to the alias cleanup alone.
Decision: retain both original observations and add one parent-source baseline
with the same Tippy arguments, compiler, profile and V8 inputs. Compare that
against the already completed cleanup-source run; repeating the fixed run is
unnecessary unless its actual tool or input identity differs.
